## Project Title: The Water Tracker Intake Questionnaire (With Guaranteed Results!) 
## Project Description:
This is a simple python program that tracks the daily water intake of the user and determines whether they drank enough using factors like weight, exercise frequency, sex, and age.
## Features
Features:

- Enter user's name, their weight, exercise frequency, sex, water goal intake, and age.

- Show options for exercise frequency: 
A. Never
B. Rarely
C. Normally
D. Frequently
E. Always

- Calculate the base water goal in cups of the user by dividing their body weight in pounds by 16.

- Show options for biological sex:
M. Male: Adds 3 extra cups to the goal for average muscle mass needs.
F. Female: Uses the regular baseline amount.

- Shows rules based on age groups:
Under 14: Sets small goal because they have smaller bodies.
14-59: Uses the standard baseline based on body weight.
60 and above: Sets a safe minimum goal to protect older adults from dehydration.

- Ask the user's water intake and the time of the drink inside a loop until they choose to end the day, to see if they reached their target or if they need to drink more.

- Use a variable to hold the total cups of water and compare it to the goal to see if the target was achieved at the end of the day.

## How to run the program

1. Open our shared GitHub repository link.

2. Access the project workspace directly inside the browser.

3. Open a terminal panel or code viewer window.

4. Run the program by pressing F5 or clicking 'Run'.

5. Follow the on-screen instructions to enter your name, metrics, select your exercise option (A-E), enter your water intake/time, and type 'Yes' or 'No' to end the day.
